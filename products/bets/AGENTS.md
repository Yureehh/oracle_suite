# Bets rules

Inspect the existing implementation before any modification; preserve working code,
data and history. No migration is authorized during bootstrap. See this directory's
README for the inspected project snapshot; read its current docs before integration.
Do not assume provider, schema or model contracts.

Maintain source/output traceability, guard against data leakage, and use time-aware
validation where applicable. Predictions are estimates; never invent results or
backtests. Reuse Oracle components only when actual interfaces are compatible.
Bets's existing Core is not automatically equivalent to Oracle Core.
