# Lyceum rules

Reuse experiment metadata produced by existing workloads; do not duplicate training
systems. Keep experiment identifiers and artifact references traceable. Capture
configurations, seeds, versions, metrics and provenance, and preserve historical results.

Distinguish experimental runs from production models. Build analysis views only with
actual experimental data and explicit comparison criteria. Never fabricate charts or
performance comparisons. No independent Lyceum backend is part of this scaffold.
